## 1. Objective

`swiftvr/training/m11b_phase_objective.py` supplies:

```
L = w_gt * L1(A1, GT)
  + w_teacher * L1(A1, OriginalDecoder(z_SR))
  + w_HF * L1(HP(A1), HP(GT))
  + w_LFtime * L1(temporal_diff(LP(Y(A1)-Y(GT))))
  + w_phase * (smoothmax(per_phase_GT_HF_errors)-mean(per_phase_GT_HF_errors))
  + w_LPIPS * LPIPS(A1,GT)
```

- GT constrains real brightness/structure/detail and time variation.
- The Original Decoder on **the same frozen M11-B latent** is an appearance teacher only; no teacher-temporal flicker target.
- HF objective compares **per-frame output against per-frame HR**. It does not equalize the frequency content of unrelated motion frames.
- LPIPS uses existing fully local AlexNet weights, fails closed if unavailable; no implicit download.
- Internal phase labeling for a full 13-frame clip is `(t+3)%4`. This does not establish long-video cross-chunk quality.

Default weights are *pilot hyperparameters*, not claimed as validated.
